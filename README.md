# EX No.6.2.DESIGN THE VARIOUS PARTS OF A MECHANICAL COMPONENT AND ASSEMBLE
## DATE:

## AIM: 
To Design the various parts of a mechanical component and assemble it using a bottom-up approach then convert it into the orthographic view

## REQUIREMENTS: 
1. Autodesk fusion 360
2. Windows 10
3. 4 GB of RAM (integrated graphics recommend 6 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## COMMANDS USED:
### Align: 
The Align tool allows you to align, distribute or organize selected elements, annotations, tags and text along the axis you specify. Furthermore, the Arrange feature will automatically neatly place your tags around the current view.
The Align plug-in for Autodesk® Revit® can help to save time while producing complex drawings with large sets of annotation.
Just select a few elements and the Align tool will sort them for you.

### Derive:
Insert design elements such as Components, Bodies, Sketches, Work geometry, Flat patterns or parameters from another design.
The inserted elements update with changes to the original design

### Move: Moves the selected face, body, sketch, or construction geometry a specified distance or angle.
Select the objects to modify then specify the distance or angle. Use set pivot to reposition the manipulator

## PROCEDURE:
Part 1 – Create the seat
Step 1: Create a new design
1. Open Autodesk Fusion 360.
2. Click File → New Design.
3. Click Create Sketch.
4. Select the XY plane.
Step 2: Draw the seat
1. Select Rectangle → 2-Point Rectangle.
2. Draw the seat rectangle.
3. Press D to apply dimensions.
4. Enter the seat length and width according to the drawing.

Step 3: Extrude the seat
1. Click Finish Sketch.
2. Press E (Extrude).
3. Select the rectangle profile.
4. Enter the seat thickness of 6 mm.
5. Click OK.
Your chair seat is ready.
Part 2 – Create the four chair legs
Step 4: Create the front legs
1. Click Create Sketch and select the front plane.
2. Select Rectangle → 2-Point Rectangle.
3. Draw the left front leg below the seat.
4. Set its width according to the drawing.
5. Draw the right front leg with the same dimensions.
6. Click Finish Sketch.
7. Press E (Extrude).
8. Select both leg profiles.
9. Extrude them to the required depth.
10. Click OK.
Step 5: Create the rear legs
1. Select the side plane and click Create Sketch.
2. Draw the rear leg profile using the Line tool (L).
3. Draw it vertically from the seat and extend it upward to form the back support.
4. Create the slight backward inclination according to the side view.
5. Use Extrude to give the rear legs thickness.
6. Click OK.

Part 3 – Create the backrest horizontal bar
Step 6: Draw the horizontal bars
1. Select the Front plane.
2. Click Create Sketch.
3. Use the Rectangle tool to draw the first horizontal bar between the two rear legs.
4. Set the bar thickness to 4 mm, as shown in the drawing.
5. Draw the remaining horizontal bars at the specified spacing.
6. Click Finish Sketch.
Step 7: Extrude the bars
1. Press E.
2. Select all the horizontal bar profiles.
3. Extrude them to the required depth.
4. Select Join if they are connected to the rear legs, or New Body if they are separate.
5. Click OK.
The chair backrest bars are now complete.

Part 4 – Create the backrest side supports
Step 8: Create the inclined back supports
1. Select the Side plane and click Create Sketch.
2. Select the Line tool (L).
3. Draw the inclined rear support profile from the seat level to the top of the chair.
4. Follow the side view of the drawing.
5. Apply the required height of 56 mm above the seat level.
6. Add a small rounded top using the Arc tool.
7. Click Finish Sketch.
Step 9: Extrude the back supports
1. Press E.
2. Select the back support profile.
3. Enter the required thickness.
4. Choose New Body or Join, depending on the connection.
5. Click OK.
6. Repeat for the other rear support.
<img width="418" height="202" alt="Screenshot 2026-11-24 192610" src="https://github.com/user-attachments/assets/528ac073-d1b7-4c9e-94f5-8c65b3b112cf" />

Part 5 – Create the seat support frame
Step 10: Draw the horizontal support
1. Select the front face below the seat.
2. Click Create Sketch.
3. Select the Rectangle tool.
4. Draw a horizontal rectangular support between the two front legs.
5. Set its height according to the drawing.
6. Click Finish Sketch.
Step 11: Extrude the support
1. Press E.
2. Select the rectangular profile.
3. Enter the required depth.
4. Choose Join.
5. Click OK.
<img width="328" height="357" alt="Screenshot 2026-11-24 192641" src="https://github.com/user-attachments/assets/22403099-7fea-463e-aced-6646046d7107" />

Part 6 – Final finishing
Step 12: Complete the chair
1. Use Modify → Fillet to round the top edges of the back supports.
2. Check the spacing between the backrest bars.
3. Verify that the seat is horizontal.
4. Check that all four legs are aligned properly.
5. Rotate the model using the ViewCube and inspect the front, side and isometric views.
6. Click File → Save and save the chair model.
